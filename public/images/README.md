# Como trocar as fotos deste site

A maioria das fotos já são reais (extraídas do material do MPA) — ver a tabela completa no
[README.md principal do projeto](../../README.md). Para trocar qualquer uma delas, basta
salvar o arquivo novo com o **mesmo nome exato** nesta pasta (`public/images/`) e confirmar
"substituir" — não precisa mexer em nenhum código.

## Carrossel "Nossa infraestrutura" (Grupo UniCPO / FAINTER)

Hoje tem 3 fotos: `predio-fainter-01.jpg`, `predio-fainter-02.jpg`, `predio-fainter-03.jpg`.
Para **adicionar mais fotos** ao carrossel, me avise — só precisa somar uma linha em
`src/data/facilityGallery.ts` com o nome do novo arquivo.

## Fotos dos especialistas

Seguem o padrão `esp-nome-sobrenome.jpg` (ex: `esp-glauco-melo.jpg`). Estão listadas em
`src/data/faculty.ts`.

## Como chegar nesta pasta no Windows

1. Abra o **Explorador de Arquivos**.
2. Cole este caminho na barra de endereços e pressione `Enter`:

   ```
   C:\Users\Usuario\Desktop\Landing Page\mpa-medicina\public\images
   ```

3. Arraste a foto nova para dentro, ou use "Copiar" → "Colar".

## Recomendação de tamanho

Qualquer foto serve. Para carregar rápido, o ideal é que cada foto pese menos de 1–2 MB — se
mandar algo mais pesado, é só avisar que eu comprimo.
